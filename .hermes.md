# Purpose

Fast parallel Reddit scraper supporting archive, search, monitoring, comments, SQLite persistence, export, and multiple rotating cookie/OAuth sessions.

# Decisions

- Use Chrome-compatible fingerprint plus logged-in Reddit sessions rather than unauthenticated `.json` requests.
- Historical post coverage comes from Arctic Shift per subreddit; Reddit listing depth is reserved for live `monitor`; authenticated Reddit only for optional comment expansion.
- Archive completeness is fail-closed: retry exhaustion, malformed payloads, non-ascending pages, unsafe upper-bound progression, saturated timestamp buckets, or stalls -> incomplete + exit 1, retaining persisted pages.
- Arctic Shift 422 = server load timeout: treat as retryable with patient backoff; never conclude data is missing from a 422.
- Username accuracy requires manual validation of intent/direction/horizon AND enough independent comparable calls; automatic heuristic accuracy rankings are never reported as credible.
